# Bitácoras de sesiones

## Convención

Cada sesión de trabajo relevante crea un archivo:

```
docs/sessions/YYYY-MM-DD-HHMM-<slug>.md
```

Usar hora local (Europe/Madrid).

## Formato

```md
# Sesión: <título>

- Fecha:
- Objetivo:
- Estado inicial:
- Estado final:
- Agente responsable:
- Cambio OpenSpec relacionado:
- Riesgo asumido:
- Validaciones realizadas:
- Archivos modificados:
- Comandos ejecutados:
- Resultado:
- Próximos pasos:
- Bloqueos o decisiones pendientes:
```

No crear una bitácora por cada acción mínima. Una por sesión, fase o cambio relevante.
