# Glosario

| Término | Definición |
|---------|------------|
| Short / TikTok / Reel | Vídeo vertical corto (9:16, duración 15-60s) |
| JobId | Identificador único de trabajo: `hist-YYYY-MM-DD-NNN` |
| Pipeline | Secuencia de pasos desde el tema hasta el MP4 listo para revisión |
| Render | Generación del vídeo final a partir de audio, imágenes y subtítulos |
| SRT | Formato de subtítulos con timestamps |
| TTS | Text-to-Speech, conversión de texto a voz |
| LLM | Large Language Model, usado para generar guiones |
| OpenSpec | Sistema de especificación de cambios basado en archivos |
| ADR | Architecture Decision Record, registro de decisión arquitectónica |
| Gate | Punto de control donde se requiere intervención humana |
| Scene | Escena individual del vídeo (visual + fragmento de narración) |
| Hook | Frase de apertura diseñada para enganchar al espectador |
